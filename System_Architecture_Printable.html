System Architecture Specification

Blockchain-Based Digital Warranty Management System

Sepolia Ethereum Testnet

1. Executive Summary & Presentation Script

"Our system follows a 4-tier decentralized application (dApp) architecture where the Ethereum blockchain acts as the single source of truth, completely eliminating centralized databases, IPFS nodes, or backend servers.

The architecture connects four major layers: Presentation Layer (React.js), Web3 Abstraction Layer (Ethers.js v6 & MetaMask), Smart Contract Business Logic Layer (Solidity WarrantyManagement.sol), and Ledger Persistence Layer (Sepolia Ethereum Testnet)."

3. Layered Architectural Breakdown

Layer 1: Presentation Layer (React.js)

  • Role-Based Navigation: Renders custom portals for Admin, Manufacturer, Retailer, Customer, and Service Center based on connected wallet roles.
  • State Management: Maintains live wallet status, network detection, and transaction modal states.
  • UI Component Library: Custom CSS modular components (StatusBadge, AlertMessage, TransactionModal).

Layer 2: Web3 Abstraction Layer (Ethers.js v6 & MetaMask)

  • Provider & Signer: Uses BrowserProvider for cryptographic transaction signing and public JSON-RPC fallbacks for read-only queries.
  • Network Guard: Enforces Sepolia Testnet (Chain ID: 0xaa36a7 / 11155111) and triggers automatic RPC network switching.
  • Error Parsing: Maps raw EVM revert strings to human-readable error banners.

Layer 3: Smart Contract Business Logic (WarrantyManagement.sol)

  • Role-Based Access Control (RBAC): Enforces strict access control via custom modifiers (onlyAdmin, onlyManufacturer, onlyRetailer, onlyServiceCenter).
  • Dynamic Timestamp Calculation: Evaluates warranty expiration dynamically against block timestamps:
    Status = (block.timestamp <= expiryDate) ? ACTIVE : EXPIRED
  • Event Emmiters: Logs indexed events for auditability (ProductRegistered, WarrantyCreated, ProductAssigned, ClaimCreated, ClaimStatusUpdated).

Layer 4: Ledger Persistence Layer (Sepolia Testnet)

  • Decentralized State Storage: Stores only essential structured data structs (Product, Warranty, Claim) to maintain zero traditional database dependencies.
